# 📊 Personal Data Summarizer

An interactive **Streamlit-based Data Analysis Tool** that automatically summarizes CSV and Excel datasets, generates key insights, and visualizes data through interactive charts.

This project helps users quickly understand their datasets without writing complex code, making data exploration faster and more efficient.

---

## 🚀 Features

- 📂 Upload CSV & Excel files
- 📋 Dataset Preview
- 📊 Dataset Overview (Rows, Columns, Data Types)
- 📈 Summary Statistics
- 🔍 Missing Value Analysis
- 📌 Duplicate Detection
- 📉 Correlation Heatmap
- 📦 Box Plot
- 📊 Histogram
- 📍 Scatter Plot
- 🚨 Outlier Detection (IQR Method)
- 📥 Download Summary Report
- 🎯 Automatic Key Insights
- 🎨 Interactive Dashboard using Streamlit

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- OpenPyXL


## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/personal-data-summarizer.git
```

### Navigate to the project directory

```bash
cd personal-data-summarizer
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```

---

## 📊 How It Works

1. Upload a CSV or Excel file.
2. The application automatically analyzes the dataset.
3. View summary statistics and data quality information.
4. Explore interactive visualizations.
5. Detect missing values, duplicates, and outliers.
6. Download the generated summary report.
